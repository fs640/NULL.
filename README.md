# NULL. - Sneakers Brand

## About the Project
NULL. adalah brand sneakers yang mengusung gaya modern, minimalis, dan ekspresi diri. Website ini dibuat untuk memperkenalkan identitas brand NULL. serta menampilkan koleksi produk sneakers melalui desain website yang menarik

Proyek ini dikembangkan sebagai bagian dari penugasan BSO Catalyst Weekly Meet.

## Project Objectives

Tujuan dari proyek ini adalah:
- Memperkenalkan brand NULL. dan identitas visualnya.
- Menampilkan katalog produk sneakers original NULL.
- Memberikan informasi yang relevan kepada pengunjung mengenai brand dan produknya.
- Menerapkan dasar pengembangan website menggunakan HTML, CSS, dan JavaScript.
- Melatih kolaborasi tim menggunakan Git dan GitHub

## Website Sections & Features

Website NULL. terdiri dari beberapa bagian utama:

- Home/Hero Section — Menampilkan nama brand, pengenalan singkat, dan navigasi website.
- About — Menjelaskan identitas, konsep, dan latar belakang brand NULL.
- Product Catalog — Menampilkan koleksi produk streetwear dan sneakers NULL.
- Contact & Footer — Menyediakan informasi kontak atau media sosial serta tautan pendukung.

## Technologies Used

- Figma - Mendesign UI/UX Website.
- HTML — Menyusun struktur halaman website.
- CSS — Mengatur tampilan, warna, layout, dan desain website.
- JavaScript — Mengatur interaksi dan fungsionalitas website.
- Git & GitHub — Mengelola versi kode dan kolaborasi tim.
- Visual Studio Code — Digunakan untuk proses pengembangan website.
